# Support

aokit is maintained by one person, so support is best-effort.

- **Bugs:** open an issue with the [bug report form](https://github.com/andryorelabs/aokit/issues/new?template=bug_report.yml).
- **Feature ideas:** open an issue with the [feature request form](https://github.com/andryorelabs/aokit/issues/new?template=feature_request.yml). Check the [roadmap](ROADMAP.md) first.
- **Security vulnerabilities:** never in a public issue. Follow [`.github/SECURITY.md`](.github/SECURITY.md).
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Only the latest release is supported.
