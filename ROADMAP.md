# Roadmap

aokit scaffolds and keeps up to date the foundations of a Project from versioned Modules served by a Registry. This is the short public view; the detailed implementation phases are in [docs/roadmap.md](docs/roadmap.md).

## Direction

- A distributable CLI with a stable release pipeline.
- A growing Registry of Modules, with updates and migrations that preserve user edits.
- Agent-friendly output: an MCP server and generated agent files.
- Clear, well-documented Project output that you can read, own and edit.

## Out of scope

- Hosting or running your Project after it is generated.
- Replacing your framework, bundler or package manager.
- Managing files that no Module owns.
- Support for package managers other than the ones the Modules declare.

The full phase list, including what is deliberately deferred, lives in [docs/roadmap.md](docs/roadmap.md).
