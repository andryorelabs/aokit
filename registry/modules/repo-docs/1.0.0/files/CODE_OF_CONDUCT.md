# Code of conduct

We want participation in this project to be a harassment-free experience for everyone.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Personal or political attacks.
- Publishing others' private information without permission.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code of conduct. Report problems privately to the maintainers listed in `GOVERNANCE.md`.
