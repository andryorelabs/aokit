# Working with TanStack Router

1. Routes are files in `src/routes/`; a file there is a route (`about.tsx` serves `/about`, `posts/$postId.tsx` serves `/posts/:postId`).
2. Each route file exports `Route`, created with `createFileRoute("<path>")`. `src/routes/__root.tsx` is the root layout and renders `<Outlet />`.
3. `src/routeTree.gen.ts` is regenerated by the Vite plugin while `bun run dev` or `bun run build` runs. Never edit it by hand; commit it.
4. `src/router.tsx` creates the router from the route tree and replaces the vite-react route table.
5. The plugin is registered in `plugins` in `vite.config.ts`. It must run before the React plugin; move it first if the order is wrong.
6. Navigate with `<Link to="/about">` and `useNavigate`; paths are type-checked against the route tree.
7. Do not add `web.routes` contributors: the router override replaced the file that Extension point anchors in, so routes belong in `src/routes/`.
