# Governance

## Maintainers

Maintainers review and merge changes. The current maintainers are listed in `.github/CODEOWNERS`.

## Decisions

Day-to-day decisions are made in pull requests and issues. Larger or hard-to-reverse decisions are recorded as architecture decision records when the project uses them.

## Becoming a maintainer

Maintainers invite contributors who show sustained, high-quality participation.
