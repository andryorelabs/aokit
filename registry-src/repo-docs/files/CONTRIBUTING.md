# Contributing

Thanks for helping out.

## Workflow

1. Branch from `main`; never push directly to `main`.
2. Keep each change small and focused.
3. Run the project checks before opening a pull request.
4. Describe why the change is needed in the pull request.

## Commits

Use conventional commits, for example `feat: add user authentication`.

## Reporting issues

Include what you expected, what happened, and the steps to reproduce.
